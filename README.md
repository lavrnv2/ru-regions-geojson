# ru-regions-geojson

Границы 85 субъектов Российской Федерации в GeoJSON для карт регионов (Metabase и др.).

Файл: `ru-regions.geojson` — FeatureCollection, у каждого объекта свойства:

- `name` — название субъекта («Москва», «Московская область», «Республика Саха (Якутия)» …);
- `code` — код ISO 3166-2 (`RU-MOW`, `RU-MOS`, `RU-SA` …; Крым — `RU-CR`, Севастополь — `RU-SEV`).

Восточная часть Чукотки (за 180° в. д.) записана долготами 180…191 вместо −180…−169, чтобы
границы карты охватывали Россию, а не весь земной шар (иначе Leaflet / Metabase рисуют её мелко).

Объекты отсортированы по коду, так что города федерального значения рисуются поверх окружающих
областей (`RU-MOS` → `RU-MOW`, `RU-LEN` → `RU-SPE`, `RU-CR` → `RU-SEV`). Координаты округлены до
3 знаков (~100 м).

## Источник и лицензия

[Natural Earth](https://www.naturalearthdata.com/), Admin 1 — States, Provinces, масштаб 1:50m
(`ne_50m_admin_1_states_provinces.geojson` из репозитория
[nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector), коммит
`ca96624a56bd078437bca8184e78163e5039ad19`). Natural Earth — **общественное достояние (public domain)**;
этот файл — производный от него и тоже передаётся в общественное достояние.

## Что исправлено относительно Natural Earth

- **Москва и Московская область:** у Natural Earth коды перепутаны (объект «Москва» с кодом `RU-MOS`,
  «Московская область» — с `RU-MOW`); здесь `RU-MOW` — город Москва, `RU-MOS` — область.
- **Алтайский край:** у Natural Earth `name_ru` «Республика Алтай» у двух объектов; объект `RU-ALT`
  (Барнаул) назван «Алтайский край», `RU-AL` (Горно-Алтайск) — «Республика Алтай».
- **Крым и Севастополь:** у Natural Earth коды `UA-43` / `UA-40` и название «Автономная Республика
  Крым»; здесь `RU-CR` «Республика Крым» и `RU-SEV` «Севастополь».
- Названия всех субъектов приведены к официальной форме («Республика Татарстан», «Чеченская
  Республика», «Ханты-Мансийский автономный округ — Югра» …), оставлены только объекты России.

Донецкой и Луганской народных республик, Запорожской и Херсонской областей в исходных данных
Natural Earth как субъектов РФ нет — в файле их тоже нет.

Файл собирается скриптом `scripts/build-geo.py` проекта lumi-analytics.
